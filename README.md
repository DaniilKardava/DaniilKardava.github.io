# Daniil Kardava — Project Portfolio

Source for [daniilkardava.github.io](https://daniilkardava.github.io/), a collection of computational research and software case studies.

## Structure

- index.html — portfolio landing page
- projects/ — individual project case studies
- assets/ — shared styles and scripts
- projects/<project>/artifacts/ — curated, presentation-ready results used by a case study

Full source code and large/raw experimental data remain in their original project repositories. This repository keeps only the compact artifacts needed to present and support each result.
