Building a 2048 agent—twice.

Two versions of the same reinforcement-learning idea: first implement the neural-network machinery from scratch, then use TensorFlow and Keras to train, save, and visualize an agent that reaches the 2048 tile.

Why 2048?

Every move changes what will be possible later.

2048 has only four actions—left, right, up, and down—but choosing well requires more than collecting the largest immediate merge. A move rearranges the whole board, a new tile appears at random, and a locally rewarding choice can destroy the structure needed to survive many turns later.

That makes the game a compact reinforcement-learning problem. The agent must learn a policy under randomness, delayed consequences, a changing set of legal moves, and an enormous number of possible board configurations.

The project begins below the learning algorithm: it implements the game rules, transition function, rewards, terminal condition, and feature encodings from scratch.

Two implementations

Understand the machinery. Then use the tools.

The two projects share the 2048 environment and actor–critic strategy, but answer different engineering questions.

01 · From scratch

Build the learning stack.

A NumPy/SciPy implementation supplies convolutional and dense layers, forward and backward passes, activation derivatives, weight initialization, Adam and SGD updates, action masking, and the actor–critic learning rule.

02 · With libraries

Scale the experiment.

The TensorFlow/Keras version expresses the policy and value models with standard layers and automatic differentiation, making it practical to train longer, save checkpoints, reload policies, and record complete games.

From scratch

The first version builds the machinery, not just the agent.

NumPy and SciPy provide arrays and numerical primitives, but the environment, neural-network layers, gradients, optimizers, and actor–critic update are implemented directly.

01 · Environment

Make 2048 a learning problem.

I implemented board movement and merging, random tile generation, rewards, terminal states, valid-action checks, and an 11-channel encoding of the 4×4 board.

02 · Network layers

Build forward passes from arrays.

Custom convolutional and dense layers turn the encoded board into learned features, with explicit activation functions, derivatives, and weight initialization.

03 · Backpropagation

Carry the learning signal backward.

Each layer computes its own parameter and input gradients. The implementation includes both SGD and Adam updates rather than relying on automatic differentiation.

04 · Actor–critic

Connect prediction to control.

The policy samples among valid moves, the value model estimates future return, and their difference supplies the advantage used to update both networks.

Representation

Each tile becomes one of 11 channels in a 4×4 tensor. The actor and critic receive the same representation but process it through separate convolutional networks with separate weights.

Policy head

The actor assigns probabilities to left, right, up, and down. Invalid moves are masked before sampling so the agent only chooses actions that change the board.

Value head

The critic estimates the return available from the current state. Comparing that estimate with the observed transition produces the advantage signal.

Update

A positive advantage makes the sampled move more likely; a negative advantage makes it less likely. The value network simultaneously learns to make a better prediction.
