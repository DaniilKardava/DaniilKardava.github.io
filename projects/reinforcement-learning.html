Building a 2048 agent—twice.

Two versions of the same reinforcement-learning idea: first implement the neural-network machinery from scratch, then use TensorFlow and Keras to train, save, and visualize an agent that reaches the 2048 tile.

Why 2048?

Every move changes what will be possible later.

2048 has only four actions—left, right, up, and down—but choosing well requires more than collecting the largest immediate merge. A move rearranges the whole board, a new tile appears at random, and a locally rewarding choice can destroy the structure needed to survive many turns later.

That makes the game a compact reinforcement-learning problem. The agent must learn a policy under randomness, delayed consequences, a changing set of legal moves, and an enormous number of possible board configurations.

The project begins below the learning algorithm: it implements the game rules, transition function, rewards, terminal condition, and feature encodings from scratch.

Treat the bootstrapped target as fixed and move V(st) toward it. This improves the baseline used to judge later actions.

Actor update Lπ = −At log π(at | st)

Positive advantage reinforces the sampled action; negative advantage suppresses it. Only the chosen action’s log-probability enters this update.

No weights are shared between actor and critic.Advantage At is the bridge: critic supplies the baseline; actor uses the verdict.
State + mask

The 11×4×4 tensor represents the board. Before softmax, logits for moves that do not change the grid are set to negative infinity, so invalid actions receive zero probability.

Transition

The environment moves and merges tiles, prevents a tile from merging twice in one move, sums the newly created tile values as reward, and spawns a 2 with probability 0.9 or a 4 with probability 0.1.

Critic

For a nonterminal move, reward plus the next-state value becomes the target. At the terminal state there is no bootstrap term. The value gradient is proportional to −At.

Actor

The policy gradient is proportional to −At/π(at|st) before the softmax Jacobian is applied. This is the derivative of the negative advantage-weighted log-probability.

Together

The critic learns what return to expect; the actor learns which action beats that expectation. As the actor changes the visited states, the critic must continually update its baseline on the new experience.

Two implementations

Understand the machinery. Then use the tools.

The two projects share the 2048 environment and actor–critic strategy, but answer different engineering questions.

01 · From scratch

Build the learning stack.

A NumPy/SciPy implementation supplies convolutional and dense layers, forward and backward passes, activation derivatives, weight initialization, Adam and SGD updates, action masking, and the actor–critic learning rule.

02 · With libraries

Scale the experiment.

The TensorFlow/Keras version expresses the policy and value models with standard layers and automatic differentiation, making it practical to train longer, save checkpoints, reload policies, and record complete games.

From scratch · inside the implementation

Four layers of work beneath the agent.

The scratch version is more than a hand-written training loop. It follows one move through spatial computation, a reusable layer system, two explicit learning gradients, and a stateful optimizer.
